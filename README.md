# 漫译 · AI Manga Translator

运行在 Windows 本机的漫画翻译工具。双击程序启动，在浏览器中上传漫画，使用你配置的视觉模型识别并翻译文字，清除原文、调整译文排版并导出 PNG。

界面使用中文。主要由 HTML、CSS、JavaScript 和 C# 编写，使用 ChatGPT / Codex 辅助开发。（这一段README全是gpt写的，我就写了个雏形，真是被ai现在的能力震惊到了）

## 功能

- 识别漫画中的日语、英语、韩语等文字，翻译成选定目标语言。
- 内置 OpenAI、Gemini、DeepSeek、Qwen、智谱和 SiliconFlow 配置模板，以及自定义 OpenAI 兼容接口。
- 保存多个配置，分别管理接口地址、密钥、模型和翻译风格。
- 测试当前表单的连接；可用程序生成的小数字图检查图片识别。
- 自动清除对白气泡内部的原文字形，保留气泡轮廓。
- 独立编辑译文，支持拖动、缩放、删除、横竖排及坐标输入。
- 选择 Noto Sans SC、Noto Serif SC、霞鹜文楷或系统微软雅黑。
- 预览与 PNG 导出共用同一画布，保持原图像素尺寸，编辑框线不导出。
- 查看原图、清除原文后的图片或最终译制图片。

## 快速开始

运行环境：Windows 和 .NET Framework。

1. 下载完整项目并解压，保留文件夹结构。
2. 双击 `MangaTranslator.exe`。
3. 程序打开浏览器，地址为 **http://127.0.0.1:11451**。
4. 点击“模型 API 配置”，选择接口模板，填写对应服务的 API 密钥。
5. 点击“测试连接”，确认结果后保存配置。
6. 上传漫画，点击“识别并翻译”，检查并编辑译文后下载 PNG。

右下角通知区域中的程序图标可再次打开网页或退出服务。更新网页文件后，可按 **Ctrl+F5** 强制刷新浏览器。

## API 配置

模板自动填入接口地址和示例模型；地址和模型都能继续修改。模型是否可用取决于账户权限及服务商当前的模型目录。

“用模板新建”增加一份独立配置。主界面的配置下拉框用于切换已保存的配置。

自定义接口需要兼容 Chat Completions 请求格式，可以填写基础地址或完整的 `chat/completions` 地址。图片识别需要支持图片输入的模型。

测试连接使用当前表单内容，无需先保存。默认生成并发送一张数字测试图，不发送已上传的漫画；取消“同时检查图片识别”则只测试文字请求。测试会调用真实模型，可能产生少量 API 费用。取消等待不保证服务商停止处理或计费。

## 图片编辑

原文清除层与译文层独立：移动或删除译文框不会让已清除的原文字形重新出现。译文没有矩形白底，并在识别出的对白气泡内部裁切。

拖动框移动译文，拖动右下角把手调整排版范围。侧栏支持修改文字、方向、位置、宽高和删除译文框；选中框后也可以按 Delete 删除。

## 当前限制

- 气泡以外的纹理背景和拟声字采用简单笔画修复，可能需要人工修图；可选择只处理对白气泡。
- 识别位置与翻译质量取决于视觉模型，漏字和错误位置需要人工校正。
- 当前编辑单张图片；识别请求会将长边超过 1800 像素的图片缩小后发送，导出仍使用原图尺寸。
- 图片文件限制为 20 MB、2400 万像素。
- 连接测试成功代表当前请求完成，不保证所有漫画都能正确识别或翻译。
- API 模板与测试连接代码完成了 JavaScript 语法检查，尚未覆盖所有服务商的真实调用。

## 数据与运行方式

本地服务仅监听 `127.0.0.1:11451`。图片识别与翻译请求由本地程序转发至所配置的 API 服务商。

API 配置和字体偏好保存在浏览器的 `localStorage` 中，包括明文 API 密钥。项目源码不包含使用者的密钥；清除浏览器站点数据会删除这些配置。

## 从源码构建

双击 `build.bat`。脚本调用 Windows .NET Framework 的 C# 编译器，生成 `MangaTranslator.exe`。

编译失败时确认系统中存在 .NET Framework 编译器。替换正在运行的 EXE 前，先通过托盘退出旧程序。
