漫译 · 本地漫画翻译

启动
1. 双击 MangaTranslator.exe。
2. 程序会在本机启动服务并打开浏览器：http://127.0.0.1:11451
3. 右下角通知区域会出现程序图标。右键图标可再次打开网页或退出服务。

网页和字体文件需要与 EXE 一起保存在同一文件夹结构中：
- MangaTranslator.exe
- MangaTranslator.exe.config
- index.html
- app.js
- api-presets.js
- connection-test.js
- image-engine.js
- fonts\*.woff2

如果没有 MangaTranslator.exe，可在已安装 .NET Framework 的 Windows 电脑上双击 build.bat 生成。

端口只绑定本机回环地址 127.0.0.1，不对局域网或公网开放。图片翻译请求经本地程序转发到你在网页中配置的 API 服务。

字体许可文件位于 fonts 文件夹。微软雅黑选项调用 Windows 上已安装的微软雅黑，不随程序分发。

原文清除与译文编辑
1. 上传原始漫画，选择支持图片识别的模型配置，点击识别并翻译。
2. 程序根据原文位置识别气泡内部，清除原文字形并保留气泡边界。译文使用透明背景，不铺白色矩形。
3. 拖动译文框或拖动右下角把手调整排版；侧栏可修改文字、方向、位置和宽高，也可删除译文框。
4. 原文清除范围独立于译文框，移动或删除译文不影响已经清除的原文。
5. 画布显示可切换译制图片、清除原文后的图片、原图。下载导出当前画布，保留原始像素尺寸，编辑框线和把手不导出。
6. 气泡以外的复杂纹理、人物上的文字和拟声字采用简单笔画修复，可能需要进一步人工修图。可选择“只处理对白气泡”避免处理此类文字。

更新后如果浏览器仍显示旧界面，请按 Ctrl+F5 刷新，重新上传原图并识别翻译。API 配置和字体偏好保存在本机浏览器中。

硅基流动配置
接口地址：https://api.siliconflow.cn/v1
模型必须支持图片输入，复制平台模型广场提供的完整模型 ID；例如官方视觉调用示例中的 Qwen/Qwen2.5-VL-72B-Instruct，是否可用以你的账号和平台当前提供的模型为准。
DeepSeek-V3.2 和 R1 是文本模型，不能用于当前的漫画图片识别流程。
如遇 SSL/TLS 安全连接错误，请先通过托盘退出旧程序，再启动本文件夹中更新后的 MangaTranslator.exe。更新版启用 TLS 1.2，保留证书验证。

接口模板
1. 打开“模型 API 配置”，在“接口模板”中选择 ChatGPT/OpenAI、Gemini、DeepSeek、Qwen、智谱或 SiliconFlow。
2. 选择模板自动填入当前表单的地址和视觉示例模型，保存后生效。切换到其他服务时会清空表单中的旧密钥，请填写该服务的密钥。
3. 想增加一套配置，选择模板后点击“＋ 用模板新建”，填写密钥并保存。原来的已保存配置仍可通过下拉框切回。
4. “自定义”保留表单中的地址和模型，可填写第三方或本机 OpenAI 兼容接口；内置模板的地址和模型也都可以修改。
5. 模板的“官方说明”链接可查看当前可用模型及调用方式。示例模型可用性取决于账户权限和服务商的当前模型目录。
6. Qwen 模板使用百炼北京地域地址，其他地域或业务空间需改为对应地址；Gemini 需要本机网络能连接 Google 服务。
7. DeepSeek 官方模板使用支持图片输入的 deepseek-flash，与硅基流动的 DeepSeek-V3.2 文本模型是不同的调用配置。

模板信息来自各服务官方接口文档，记录日期为 2026-10-06。此次更新没有调用真实密钥或付费模型。

测试连接
1. 在配置窗口填写接口地址、模型名称和密钥，点击“测试连接”；使用的是当前表单内容，无需先保存。
2. 默认勾选“同时检查图片识别”，程序发送自己生成的数字测试图，确认模型能否识别图中的数字，不发送你上传的漫画。
3. 取消勾选后只发送简短文字请求；连接成功不代表模型支持漫画图片输入。
4. 测试调用真实模型，可能产生少量 API 费用。结果显示 HTTP 状态、耗时和回复；失败时提示密钥、模型权限、余额、限流或网络原因。
5. 最多在网页等待 60 秒，可点击“取消等待”。取消只停止本地等待，已经发出的请求仍可能由服务商处理和计费。
6. 修改地址、模型或密钥以及切换配置后，旧测试结果作废，需要重新测试。
